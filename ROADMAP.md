# QR Dine OS - Product Roadmap (ROADMAP.md)

## Current Milestone (v1.0.0 - Production Foundation)
- [x] Secure Cryptographic QR table resolution and token rotation.
- [x] Rich digital menu with categories, variants, add-ons, dietary flags, and 86'd state.
- [x] Mobile-first customer ordering with live server pricing and tax calculation.
- [x] Full Order State Machine (`RECEIVED`, `ACCEPTED`, `PREPARING`, `READY`, `SERVED`, `COMPLETED`, `CANCELLED`).
- [x] Interactive Kitchen Display System (KDS) with timers, urgency color coding, and item checkoffs.
- [x] Operations & Owner Dashboard with live floor occupancy, order management, and cash collection desk.
- [x] Sandbox payment gateway integration with HMAC signature verification and cash collection workflow.
- [x] Server-Sent Events (SSE) real-time event bus.
- [x] Comprehensive documentation suite and automated unit test suite.

## Milestone v1.1.0 (Q1 2027)
- [ ] Table-level bill splitting (split equally or split by specific ordered items).
- [ ] Direct Thermal ESC/POS receipt printer bridge via Web Bluetooth/USB.
- [ ] Diner call-waiter and request-water physical button alerts.

## Milestone v1.2.0 (Q2 2027)
- [ ] Kitchen station routing (Bar station vs Grill station vs Dessert station).
- [ ] Customer SMS/WhatsApp order readiness notifications.
